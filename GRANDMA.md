What this is
A tiny website that answers simple questions using a smart helper. You type a question, the site asks the helper, and it shows the answer.

How to use it
Open the webpage, type your question, press the button, read the reply.

What it does honestly
It sends only the words you type to the helper and shows the helper’s reply. It is not a person and can make mistakes.

Where things are
frontend/ — the webpage.
backend/ — the small program that talks to the helper.
